SQL Energy Analysis — Sustainability Portfolio

16 SQL queries applied to a 12-month building 
energy dataset. Building: 5,000 m2 commercial 
office, UAE region.

What this demonstrates:
SELECT, WHERE, ORDER BY, GROUP BY, HAVING, 
SUM, AVG, COUNT, MIN, MAX, TOP, DISTINCT, 
BETWEEN, ROUND, ISNULL, IS NULL, subqueries

Key finding:
HVAC accounts for 62.8% of total energy in 
July — peak month. Validated against Power BI 
dashboard findings using the same dataset. 
All queries run on Microsoft SQL Server 2022 Express.
